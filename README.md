# IoT Water Quality Monitoring System

This project monitors water quality using ESP32 and multiple sensors.

## Components
- ESP32
- TDS sensor
- Ultrasonic sensor
- DHT11 temperature sensor
- LEDs and buzzer

## Features
- Real-time monitoring
- Overflow detection
- Mobile web interface
- LED alert system

## Technologies
- ESP32
- Arduino framework
- PlatformIO
